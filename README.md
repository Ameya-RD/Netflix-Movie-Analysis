# 📽️ Investigating Netflix Movies

This project was completed as part of a DataCamp course titled **"Investigating Netflix Movies"**. It involves data analysis and visualization using Python to uncover insights from a dataset of Netflix movies and TV shows.

## 🔍 Project Overview

The main objectives of this project were to:
- Explore trends in movie release years on Netflix
- Analyze the duration of movies over time
- Identify popular genres and categories
- Understand Netflix's content strategy through visual insights

## 🛠️ Tools & Technologies Used
- **Python** (Jupyter Notebook)
- **Pandas** for data manipulation
- **Matplotlib** and **Seaborn** for data visualization
- **Jupyter Notebook** for combining code and narrative
